# URS

Universal RPG Engine — совместная браузерная экспедиция. Создайте мир и героя, пригласите друга, снарядитесь у тайника и зажгите маяк в башне. Прогресс сохраняется на сервере.

Для локальной игры нужны Node.js 24.12+ и npm. Выполните `npm ci`, `npm run build`, затем `npm start`. Откройте http://localhost:4173. Для проверки используйте `npm run tools:install-secrets` и `npm run verify` с установленным Chrome.
